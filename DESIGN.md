# AB Studio — guía de diseño

## Dirección visual

La página combina minimalismo editorial y una base cálida para presentar a AB Studio como un estudio digital cercano y profesional. Usa espacios amplios, separadores finos, tarjetas limpias y una jerarquía tipográfica marcada. El verde salvia se reserva para énfasis puntuales.

## Paleta de color

| Variable | Valor | Uso |
|---|---|---|
| `--paper` | `#F2EEE5` | Fondo principal crema. |
| `--paper-deep` | `#E9E3D8` | Fondos alternos y secciones destacadas. |
| `--ink` | `#252522` | Texto principal, botones y fondos oscuros. |
| `--ink-soft` | `#4F4E49` | Texto secundario. |
| `--muted` | `#79766F` | Etiquetas y notas de apoyo. |
| `--line` | `rgba(37, 37, 34, 0.17)` | Bordes y divisores sutiles. |
| `--cream` | `#EEE8DC` | Texto claro en superficies oscuras. |
| `--taupe` | `#B8AA94` | Detalles cálidos y líneas de acento. |
| `--green` | `#596351` | Acento verde salvia. |
| `--white` | `#FFFDF8` | Tarjetas y superficies elevadas. |

## Tipografía

- **Títulos y encabezados:** `Georgia, "Times New Roman", serif`.
- **Texto, navegación e interfaz:** `Inter, ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`.
- Los encabezados usan pesos ligeros, interlineado compacto y espaciado negativo para el tono editorial. El texto corrido prioriza lectura cómoda y contraste.

## Composición e interacción

- Diseño adaptable a escritorio y móvil, con contenedor centrado y márgenes fluidos.
- Navegación de una página con desplazamiento suave a las secciones.
- Tarjetas con bordes delicados, esquinas discretas y variaciones de fondo crema.
- Botones principales en carbón; acciones secundarias transparentes con borde.
- El modo oscuro conserva los mismos roles semánticos y adapta los valores desde las variables CSS.
- El selector de idioma alterna entre inglés y español.
